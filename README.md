# MAEA — Website Oficial

Website institucional da MAEA, especialistas em gestão da qualidade e certificação ISO em Angola.

## Stack

- **Framework**: Next.js 13 (App Router, TypeScript)
- **Estilo**: Tailwind CSS
- **Ícones**: Heroicons
- **Deploy**: Render / Vercel

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
